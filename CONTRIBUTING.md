# Contributing

Contributions should improve the accuracy and usefulness of this independent study aid.

## Question quality

- Write original practice questions; do not copy live exam questions or proprietary question-bank material.
- Verify concepts, terminology, and correct answers against the relevant official syllabus and glossary.
- Include a clear explanation for the correct answer and, where useful, why distractors are incorrect.
- Identify the syllabus version used when introducing or revising learning objectives.
- Avoid claiming that a question is official or representative of the actual exam.

## Code and usability

- Keep each page usable as a standalone static HTML document.
- Test answer selection, submission, scoring, feedback, and reset behavior.
- Check keyboard accessibility and responsive layout.
- Do not add analytics, remote tracking, or external scripts without documenting them.

## Privacy

Do not commit personal study records, credentials, API keys, or private information.
