# ISTQB Foundation Level 4.0 — Study Roadmap

A browser-based study companion for organizing Foundation Level preparation and practicing core software-testing concepts.

This is an independent learning project. It is not an official ISTQB product, is not endorsed by ISTQB, and does not replace the official syllabus, glossary, or accredited training.

## Included

### Study roadmap

`ISTQB.html` provides a four-week study plan covering the main Foundation Level knowledge areas, along with links to recommended reference resources.

[Open the study roadmap](./ISTQB.html)

### Chapter practice

Six standalone chapter quizzes provide **80 practice questions** across the six chapters:

| Chapter | Practice questions |
|---|---:|
| 1 — Fundamentals of Testing | 20 |
| 2 — Testing Throughout the Software Development Lifecycle | 20 |
| 3 — Static Testing | 10 |
| 4 — Test Analysis and Design | 10 |
| 5 — Managing the Test Activities | 10 |
| 6 — Test Tools | 10 |

Open the individual chapter pages from the repository root.

### Final practice exam

`Final_Exam.html` contains a separate **100-question** practice exam.

[Open the final practice exam](./Final_Exam.html)

## Run locally

No build process, package manager, or backend is required.

Clone or download the repository and open `ISTQB.html` in a modern browser. The chapter quizzes and final exam are separate HTML pages and can be opened directly.

## Accuracy and versioning

The guide is labelled for Foundation Level 4.0. Exam syllabi, terminology, and learning objectives can change. Confirm all study plans, question wording, and answer explanations against the current official ISTQB syllabus and glossary before relying on them.

The practice questions are study exercises, not official ISTQB examination questions. They do not predict exam performance or guarantee syllabus coverage.

## Privacy

The pages are static client-side documents. They do not require an account or application backend. Quiz interactions run in the browser; this project does not implement server-side score storage or synchronization.
