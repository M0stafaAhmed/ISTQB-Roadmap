# ISTQB Foundation Level — Study Roadmap

A browser-based study companion for organizing ISTQB Foundation Level preparation and practicing chapter-based questions.

## Included

- A structured study roadmap.
- Separate chapter practice pages.
- A final-exam practice page.
- Static HTML, CSS, and JavaScript; no backend is required for the basic study flow.

## Run locally

1. Clone or download this repository.
2. Open the main roadmap HTML file in a modern browser.
3. Open the chapter exam pages to practice.

If the application stores progress in browser storage, that data remains local to the browser profile and is not synchronized between devices.

## Important

This is an independent study aid, not an official ISTQB product and not an endorsement by ISTQB. Use the current official syllabus and glossary as authoritative sources. Verify question wording and answers against the relevant syllabus version before relying on them for exam preparation.
